What this does:

1. Fetches all tracks from your Spotify playlist

2. Matches each track to Genius

3. Extracts top 1-3 annotated lyric snippets ("bars") per track

4. Gives you a "line bank" to copy for captions/tweets

Limitations:

- Only bars available via official Genius API

- Not all songs have annotations
